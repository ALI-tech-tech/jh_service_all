## 1.0.0

* Initial stable release of `jh_networkservice`.
* Configurable multi-base URL network service built on Dio.
* Comprehensive HTTP verbs support: `GET`, `POST`, `PUT`, `PATCH`, `DELETE`, and custom `request`.
* Standardized `ErrorModel` and `ServerException` translating Dio errors.
* Support for per-request `Options`, `CancelToken`, and progress callbacks.
* Support for custom interceptors and direct access to underlying `Dio` instance.
* Full test suite and example application.
